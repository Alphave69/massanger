# Massanger

Свой мессенджер в духе Discord — для себя и друзей. Чёрно-белый дизайн, анимации, сообщения в реальном времени.

## Что уже есть

- **Регистрация / вход** — экран со сферой из ~1600 точек: она вращается, точки разлетаются от курсора, обтекают его и возвращаются на место. Клик — ударная волна.
- **Интерфейс как в Discord** — полоса серверов, каналы, чат, список участников, панель пользователя.
- **Сообщения в реальном времени** (Socket.IO): группировка подряд идущих сообщений, разделители по дням, индикатор «печатает…».
- **Статусы** «в сети / не в сети».
- **Серверы**: создание своего, приглашение друзей по коду, вход по коду. Все новые пользователи попадают на общий сервер.
- Голосовые каналы пока заглушка — следующий этап.

## Стек

| Часть  | Технологии                                       |
| ------ | ------------------------------------------------ |
| client | React 19, TypeScript, Vite, lucide-react, шрифты локально (без Google Fonts) |
| server | Node.js, Express 5, Socket.IO, JWT, bcrypt       |
| данные | JSON-файл `server/data/db.json` (позже — БД)     |

## Запуск

**Windows, проще всего:** дважды кликнуть `start.bat` в папке проекта. Он сам поставит зависимости, запустит сервер и откроет браузер. Окно не закрывать, пока пользуешься.

**Вручную (любая ОС):**

```bash
npm install
npm run dev
```

Браузер откроется сам на http://localhost:5173 — клиент (Vite) проксирует `/api` и сокеты на сервер `:3001`.

Продакшен (один порт):

```bash
npm run build
JWT_SECRET=какой-то-длинный-секрет npm start   # http://localhost:3001
```

## Структура

```
client/src/
  components/
    ParticleSphere.tsx   сфера из точек (canvas)
    AuthPage.tsx         вход / регистрация
    AppShell.tsx         состояние приложения, сокет, модалки
    ServerRail.tsx       полоса серверов слева
    ChannelSidebar.tsx   каналы + панель пользователя
    ChatView.tsx         сообщения и поле ввода
    MemberList.tsx       участники
  lib/                   API-клиент, форматирование
  styles/                global / auth / app
server/src/
  index.ts               REST + Socket.IO
  auth.ts                пароли и JWT
  store.ts               хранилище
```
