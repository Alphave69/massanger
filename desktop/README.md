# Nuntius для Windows

Приложение — это окно с твоим сервером Nuntius: как Discord, только свой. Живёт в трее, присылает
уведомления, умеет демонстрацию экрана со звуком. Сами данные хранятся на сервере (см. `DEPLOY.md`),
поэтому сначала запусти сервер, а потом собирай приложение с его адресом.

## Собрать у себя на Windows

Нужен установленный [Node.js](https://nodejs.org) (LTS). В PowerShell из папки проекта:

```powershell
cd desktop
npm install
```

Открой `desktop\nuntius.config.json` в Блокноте и впиши адрес сервера:

```json
{ "url": "https://185-12-34-56.sslip.io" }
```

Потом:

```powershell
npm run dist
```

Через пару минут в `desktop\dist` появятся два файла:

- **`Nuntius-Setup-1.0.0.exe`** — установщик. Его и кидай друзьям: двойной клик — и готово
  (ставится без вопросов, как Discord, ярлык на рабочем столе).
- **`Nuntius-Portable-1.0.0.exe`** — запускается без установки.

Если адрес не вписать — приложение само спросит его при первом запуске.

## Собрать через GitHub (без своего ПК)

GitHub → вкладка **Actions** → **Nuntius для Windows** → **Run workflow** → впиши адрес сервера → Run.
Через ~5 минут файлы будут внизу страницы запуска, в разделе **Artifacts**.

## «Windows защитила ваш компьютер»

Приложение не подписано платным сертификатом, поэтому при первом запуске Windows SmartScreen
может показать синее окно. Нажми **«Подробнее» → «Выполнить в любом случае»**. Это один раз.

## Мелочи

- Крестик сворачивает в трей (как Discord). Выйти — правой кнопкой по значку в трее → «Выйти».
- Там же: **«Сменить сервер…»** и **«Запускать вместе с Windows»**.
- Обновлять приложение почти никогда не нужно: всё новое приходит с сервера само.
  Пересобирать стоит, только если поменялся адрес сервера или вышла новая версия оболочки.
