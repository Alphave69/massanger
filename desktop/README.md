# Nuntius для Windows

Приложение — это окно с твоим сервером Nuntius: как Discord, только свой. Своя чёрная рамка окна
(без белой полоски Windows), живёт в трее, присылает уведомления, умеет демонстрацию экрана со звуком
и **само обновляется**. Сами данные хранятся на сервере (см. `DEPLOY.md`).

## Скачать (постоянные ссылки)

Эти ссылки не меняются — по ним всегда лежит самая свежая версия, их можно один раз кинуть друзьям:

- **Установщик:** https://github.com/Alphave69/massanger/releases/download/desktop-latest/Nuntius-Setup.exe
  — двойной клик, и готово (ставится без вопросов, ярлык на рабочем столе). Дальше обновляется сам.
- **Без установки:** https://github.com/Alphave69/massanger/releases/download/desktop-latest/Nuntius-Portable.exe
  — просто запускается. Сам не обновляется: новую версию качай по той же ссылке.

## Обновления

Установленное приложение раз в 6 часов (и при запуске) тихо проверяет, нет ли новой версии, и само её
скачивает. Когда всё готово, в полоске сверху загорается кнопка **«Обновить»**: нажал — приложение
перезапустится уже новым. Не нажал — обновление поставится само, когда выйдешь из Nuntius через трей.
Нет интернета или GitHub недоступен — ничего страшного, просто попробует позже.

Обычно обновлять оболочку и не нужно: всё новое в самом мессенджере приходит с сервера сразу.

### Если у друга стоит старая версия 1.0.0

Версия 1.0.0 ещё не умела обновляться сама. Один раз нужно скачать **Nuntius-Setup.exe** по ссылке
выше и запустить поверх старой — она заменится, настройки сохранятся. Дальше — только кнопка «Обновить».

## Окно

- Сверху — своя полоска: знак Nuntius, число непрочитанных и кнопки «Свернуть», «Развернуть», «Закрыть».
  Окно можно таскать за полоску, двойной клик по ней — развернуть на весь экран.
- Крестик сворачивает в трей (как Discord). Выйти — правой кнопкой по значку в трее → «Выйти».
- Там же: **«Сменить сервер…»**, **«Запускать вместе с Windows»** и номер версии.
- Правый клик по тексту, полю ввода или ссылке — «Копировать», «Вставить», «Открыть ссылку в браузере»,
  подсказки орфографии. На сообщениях работает собственное меню мессенджера.
- **F5** или **Ctrl+R** — обновить страницу, **Ctrl+Shift+I** — инструменты разработчика.

## Выпустить новую версию (через GitHub, без своего ПК)

GitHub → вкладка **Actions** → **Nuntius для Windows** → **Run workflow** → Run (поле с адресом сервера
можно оставить пустым — возьмётся `nuntius.config.json`). Через ~5 минут новая сборка окажется по постоянным
ссылкам выше, а у всех, кто поставил приложение, загорится «Обновить».

Номер версии ставится сам: `1.1.<номер запуска>`, так что каждая сборка новее предыдущей.

## Собрать у себя на Windows

Нужен установленный [Node.js](https://nodejs.org) (LTS). В PowerShell из папки проекта:

```powershell
cd desktop
npm install
```

Адрес сервера лежит в `desktop\nuntius.config.json`:

```json
{ "url": "https://nuntius.site" }
```

Потом:

```powershell
npm run dist
```

Через пару минут в `desktop\dist` появятся **`Nuntius-Setup.exe`**, **`Nuntius-Portable.exe`** и
`latest.yml` (по нему приложения узнают о новой версии). Если адрес не вписать — приложение само спросит
его при первом запуске.

## «Windows защитила ваш компьютер»

Приложение не подписано платным сертификатом, поэтому при первом запуске Windows SmartScreen
может показать синее окно. Нажми **«Подробнее» → «Выполнить в любом случае»**. Это один раз.
