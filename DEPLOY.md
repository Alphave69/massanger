# Nuntius на сервере — чтобы работал без твоего ПК

Сейчас Nuntius живёт на твоём компьютере: выключил ПК — друзья не могут зайти.
Решение — арендовать маленький сервер в интернете (VPS). Он работает круглосуточно, а ты им управляешь
из командной строки Windows. Всё ставится одним скриптом — ниже пошагово.

## 1. Арендуй VPS (≈ 200–500 ₽ в месяц)

Подойдёт любой хостинг, который принимает российские карты. Например: **Timeweb Cloud**, **Selectel**,
**Aeza**, **VDSina**, **Beget**.

Что выбрать при создании сервера:

| Параметр | Значение |
|---|---|
| Система | **Ubuntu 24.04** (или 22.04) |
| Процессор | 1 vCPU |
| Память | 1–2 ГБ (с 1 ГБ тоже заработает — скрипт добавит подкачку) |
| Диск | от 15 ГБ |

После создания хостинг покажет **IP-адрес** (вида `185.12.34.56`) и **пароль root** — запиши их.

## 2. Адрес сайта

Голосу и камере в браузере нужен HTTPS, а для HTTPS нужен адрес. Два варианта:

- **Бесплатно и сразу** — ничего не делай. Скрипт сам предложит адрес вида
  `185-12-34-56.sslip.io` (это твой IP через дефисы). HTTPS-сертификат получится автоматически.
- **Свой домен** (например `nuntius.ru`, ≈ 200 ₽/год на reg.ru или nic.ru). В настройках домена
  добавь **A-запись**: `@` → IP сервера. Подожди 10–30 минут, пока она разойдётся по интернету.

## 3. Зайди на сервер

На Windows открой **PowerShell** (Пуск → «PowerShell») и введи, подставив свой IP:

```powershell
ssh root@185.12.34.56
```

На вопрос `Are you sure you want to continue connecting` напиши `yes`. Потом введи пароль root:
при вводе символы не видны, это нормально. Вставить из буфера — правой кнопкой мыши.

## 4. Установи Nuntius

Скопируй команды по одной:

```bash
apt-get update && apt-get install -y git
git clone -b claude/gifted-meitner-2igntz https://github.com/alphave69/massanger.git /opt/nuntius
bash /opt/nuntius/deploy/setup.sh
```

> Если репозиторий **приватный**, `git clone` спросит логин и пароль. Логин — твой ник на GitHub,
> а вместо пароля нужен токен: GitHub → Settings → Developer settings → Personal access tokens →
> Fine-grained tokens → Generate new token. Доступ: только этот репозиторий, Contents: Read-only.

Скрипт спросит:

1. **Домен** — Enter, если берёшь бесплатный адрес.
2. **Пароль приложения Яндекс-почты** — тот самый, 16 букв. Ввод не виден — так и задумано.
3. **Логин владельца** — твой логин в Nuntius (у него будет админка). Можно оставить пустым:
   владельцем станет первый зарегистрированный.

Дальше скрипт сам поставит Node.js, HTTPS (Caddy), сервер для голоса (coturn), фаервол, автозапуск
и ежедневные копии базы. В конце покажет адрес: `https://…`. Открывай и регистрируйся.

## 5. Перенести старые данные с ПК (по желанию)

Если хочешь сохранить аккаунты и переписку с домашнего запуска — в PowerShell **на своём ПК**
(не на сервере) из папки проекта:

```powershell
scp server\data\db.json root@185.12.34.56:/opt/nuntius/server/data/db.json
```

Потом на сервере:

```bash
chown nuntius:nuntius /opt/nuntius/server/data/db.json && systemctl restart nuntius
```

Все войдут заново: на сервере свой секрет для входа.

## Как обновлять

Когда в репозитории появится новая версия:

```bash
ssh root@185.12.34.56
sudo bash /opt/nuntius/deploy/update.sh
```

## Полезное

| Что | Команда |
|---|---|
| Логи в реальном времени | `journalctl -u nuntius -f` (выход — Ctrl+C) |
| Перезапустить | `systemctl restart nuntius` |
| Работает ли | `systemctl status nuntius` |
| Проверить почту | `cd /opt/nuntius && sudo -u nuntius npm run check-mail` |
| Копии базы | `ls /var/backups/nuntius` |
| Восстановить копию | `cp /var/backups/nuntius/db-ДАТА.json /opt/nuntius/server/data/db.json && chown nuntius:nuntius /opt/nuntius/server/data/db.json && systemctl restart nuntius` |
| Поменять настройки | `nano /opt/nuntius/server/.env`, потом `systemctl restart nuntius` |

## Если что-то не так

- **Сайт не открывается.** Подожди пару минут после установки — Caddy получает сертификат.
  Если свой домен — проверь A-запись. Логи HTTPS: `journalctl -u caddy -n 50`.
- **Коды не приходят на почту.** `cd /opt/nuntius && sudo -u nuntius npm run check-mail` — покажет,
  что не так (чаще всего неверный пароль приложения).
- **Голос не соединяется у части друзей.** Это сложный NAT — для него стоит TURN (coturn).
  Проверь, что он работает: `systemctl status coturn`. Порты 3478 и 49160–49200/udp открыты скриптом.
- **«Аккаунт заблокирован»** — значит, тебя заблокировали в админке 🙂

## Безопасность

- Файл `/opt/nuntius/server/.env` — пароли. Никому его не показывай и не выкладывай.
- Пароль root лучше сменить командой `passwd` после первого входа.
